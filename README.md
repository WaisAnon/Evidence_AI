# Evidence AI starter

A beginner-friendly Cloudflare Pages project with a server-side Gemini API call.

## Required secret
Set `GEMINI_API_KEY` in Cloudflare Pages > Settings > Variables and Secrets.

## Important
The first version provides general AI background only. Live DOJ, RSS, Bluesky, Mastodon, and database connectors should be added and tested one at a time after deployment.
